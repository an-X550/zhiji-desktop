# 正文空间与字号修正（v2.6.15）

用户认可当前侧栏文字大小，但右侧字体偏大、日志正文被辅助区挤压、Agent 重复标题和会话列占空间。本轮直接修复本地桌面源码与构建，不修改系统 DPI 或用户保存的页面缩放。

第一性原理：高频任务是连续输入和回看正文。日期、模板、状态、会话管理应支持正文，而不能比正文占据更多注意力。前次“控件可达”的测试不能证明写作空间足够，也不能证明字号符合用户偏好。

## 实际修改

- 右侧 workspace 独立字阶：普通界面 12px、阅读/日志正文 13px、标题按层级收敛。侧栏继续使用原始变量，实测导航仍为 14px。
- 日志高度链约束到窗口；减少外边距和卡片内边距，移除 940px 卡片宽度上限，日期与日期选择合为一行；已有记录提示改为紧凑行，正文获得剩余高度。保存栏不参与压缩；极低窗口允许外层滚动。
- Agent 删除重复页面标题和说明，仅保留外壳标题；会话列表默认收起且释放整个列，展开入口常驻；压缩会话头部，保留状态、模型设置、停止、删除确认、审批等操作。

## 同条件实测

单位为 CSS px，Windows DPI 保持原状；宽度为应用设置的内容宽度，高度因系统取整实测略有差异。日志使用同日两条历史记录提示状态和长合成正文。Agent 使用离线 DOM 合成消息检验排版，不冒充真实模型对话验收。

| 内容窗口 / 页面缩放 | 日志高度（前→后） | 日志可见行数（前→后） | Agent 消息区高度（前→后） |
|---|---:|---:|---:|
| 1440×900 / 100% | 347→560 | 11→26 | 569→669 |
| 1440×900 / 125% | 167→379 | 5→17 | 389→489 |
| 960×640 / 100% | 155→300 | 5→13 | 309→409 |

125% 下日志宽度 808→884，Agent 消息区宽度 664→924；三组均无根节点横向溢出，保存栏和发送栏均在视口内，会话列表展开/收起可用。行数按编辑器实际行高计算，不能等同于不同文本的字数容量。

原始测量：[修改前](before.json)、[修改后](after.json)。截图：[日志](after-journal-1440-1.25.png)、[Agent](after-agent-1440-1.25.png)、[小窗口 Agent](after-agent-960-1.png)、[暗色日志](after-journal-dark.png)。复现脚本：`../../scripts/check-reading-space.cjs`，使用临时隔离数据并在结束后删除。

本地验证：相关单元测试 3 文件 / 30 项通过，typecheck 与改动 TSX 的 ESLint 通过，生产 package 通过。机械样式扫描只报告原有引用边线和动画项，不在本次字号/空间范围内扩展修改。页面截图同时覆盖设置、复盘、项目、开始页；本轮无模型请求，未读取用户日志。

本轮构建位于 `out/知己-win32-x64/知己.exe`，未覆盖安装版、未发布或推送。用户提供的旧截图是字号偏好参考，没有将其误称为精确 CSS 基线；最终主观字号偏好仍以用户实际查看为准。

最终包 E2E：6 项先通过，1 项因会话列表默认收起使旧 first() 定位命中隐藏元素而失败；改为定位可见会话标题后，该项复跑通过。合计 7 passed / 2 skipped（安装版专项未执行）。
