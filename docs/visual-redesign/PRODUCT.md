# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

中文个人日志作者，使用 Windows 桌面端记录经历、阅读复盘并验证行动。来源：既有项目状态与用户本轮需求。

## Product Purpose

本地优先的日志复盘工具，以记录、反馈、后续验证形成行动闭环。

## Operating Context

生产实现为 Electron + React。本目录仅存离线视觉样板和交接材料，不是产品运行源。本轮用户明确选择视觉样板、方案和执行提示词，生产实现已在 `apps/zhiji-desktop/src/` 完成，结果见 `IMPLEMENTATION-RESULT.md`。

## Capabilities and Constraints

已有日志保存、日期/项目/模板、AI 日反馈、Agent 证据与审批、历史记录、项目及设置。保留现有真实功能与安全确认，不新增自动保存或 AI 能力。视觉方向由用户委托制定，不要求苹果风。成本优先，复用现有技术，无付费模型调用或新增产品依赖。

## Success

界面明显改善视觉品质，先验证日志样板再推广；不能仅用布局调整或测试通过证明视觉任务完成。样板合成内容必须标明，不能冒充真实用户日志。
